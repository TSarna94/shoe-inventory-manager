# Shoe Inventory Manager

## Overview

Shoe Inventory Manager is a Python-based command-line application designed to manage shoe inventory data. The system allows users to track inventory levels, search products, calculate inventory value, and identify stock items requiring restocking.

The project demonstrates object-oriented programming principles, file handling, data management, and inventory tracking functionality.

## Features

### Inventory Management

- Add new shoe records
- View all inventory items
- Search shoes by product code
- Store inventory data in a text file

### Inventory Analysis

- Identify low-stock items
- Restock inventory
- View item quantities
- Calculate inventory value

### Inventory Reporting

- View full inventory
- Display highest quantity item
- Calculate stock value per product
- Highlight products available for sale

## Application Structure

### Shoe Class

The application uses a custom `Shoe` class to represent inventory items.

Attributes include:

- Country of origin
- Product code
- Product name
- Cost
- Quantity

### Inventory Operations

Users can:

- Add inventory items
- Search inventory
- View all products
- Restock low inventory items
- Calculate inventory value
- Identify products with the highest stock levels
